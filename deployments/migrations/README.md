# SQLite 数据库初始化与迁移

所有命令在项目根目录执行。业务数据库使用纯 Go SQLite 驱动，无需 MySQL 或 CGO。
数据库建表与初始数据已包含在应用中，正常部署不需要运行数据库初始化命令或导入 SQL。

## 全新数据库

默认文件为 `data/aiops.db`，父目录自动创建。只需运行发布的二进制：

```bash
./guanlan
```

自定义路径可通过 `--conf /etc/guanlan/config.yaml` 中的 `database.dsn`，或环境变量指定。例如：

```bash
export APP_DATABASE_DSN=/var/lib/aiops/aiops.db
./guanlan --conf /etc/guanlan/config.yaml
```

首次启动会在同一事务中创建表、索引、初始菜单、权限、管理员账号和默认拨测规则组，并登记 SQLite 当前版本 `2026102201`。失败时整体回滚，下次启动可重试；并发首次启动会串行处理。已有当前版本数据库只校验版本，不重复写入初始数据或重置管理员密码。已有未知结构或不支持版本的数据库会报错退出，保留原数据。默认账号为 `admin / admin123`，首次登录后应修改密码。

SQLite 启用 WAL、外键约束、5 秒锁等待，并使用单连接串行处理写入。数据库目录需可写并持久化保存。运行期间的 `-wal` 文件可能包含尚未合并的数据；备份应使用 SQLite 备份工具，或停止应用后再复制数据库文件。

## 历史 MySQL 数据

`mysql/` 目录内已有 `V202609*.sql` 为不可修改的历史 **MySQL** 迁移，仅供旧版本维护；不得在 SQLite 上执行。切换数据库不会自动转换旧数据。需要保留 MySQL 业务数据时，应单独迁移并校验数据与关联关系。

## 后续版本

后续版本的 SQLite 升级逻辑应随二进制内置，在启动时按版本执行并记录结果，不要求部署者运行外部 SQL。当前版本自动初始化空库为 `2026102201`，并将 `2026102001` 原子升级为 `2026102201`（添加 AI 模型配置、会话模型选择和设置菜单，保留已有数据）；不支持的版本会明确报错。历史 MySQL 脚本不作为 SQLite 升级路径。
