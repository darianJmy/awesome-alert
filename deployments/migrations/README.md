# SQLite 数据库初始化

所有命令在项目根目录执行。业务数据库使用纯 Go SQLite 驱动，无需 MySQL 或 CGO。
数据库建表与初始数据已包含在应用中，正常部署不需要运行数据库初始化命令或导入 SQL。

## 全新数据库

默认文件为 `data/aiops.db`，父目录自动创建。只需运行发布的二进制：

```bash
./guanlan
```

自定义路径可通过 `--conf /etc/guanlan/config.yaml` 中的 `database.dsn`，或环境变量指定。例如：

```bash
export APP_DATABASE_DSN=/var/lib/aiops/aiops.db
./guanlan --conf /etc/guanlan/config.yaml
```

首次启动会在同一事务中创建表、索引、初始菜单、权限和管理员账号，并登记 SQLite 当前版本 `2026102201`。失败时整体回滚，下次启动可重试；并发首次启动会串行处理。已有当前版本数据库只校验版本，不重复写入初始数据或重置管理员密码。已有未知结构或不支持版本的数据库会报错退出，保留原数据。拨测任务菜单直接位于告警中心下，拨测规则组由用户自行创建。默认账号为 `admin / admin123`，首次登录后应修改密码。

SQLite 启用 WAL、外键约束、5 秒锁等待，并使用单连接串行处理写入。数据库目录需可写并持久化保存。运行期间的 `-wal` 文件可能包含尚未合并的数据；备份应使用 SQLite 备份工具，或停止应用后再复制数据库文件。

## 开发环境结构调整

当前只维护一套数据库结构，不提供旧版自动升级、历史字段回填或 MySQL 迁移脚本。
开发时更改模型后，直接调整本地 SQLite 表结构；如不需要保留数据，也可在停止服务并确认数据库路径后重新创建开发库。
已有数据库不会因重启而自动改写业务数据、菜单、权限或管理员密码。

## 查询中心菜单调整（2026-10-24）

新数据库默认提供「查询中心」，其下包含指标查询、Loki 日志查询及已有链路追踪占位入口。已有数据库可执行 `2026102401_query_center.sql` 更新默认菜单；此脚本只修改默认名称、父级和日志组件，保留菜单 ID、角色绑定及 URL，重复执行无副作用。执行前使用 SQLite backup API 备份，更新后重新登录刷新菜单。自定义过名称或父级的指标菜单不会被强制迁移，可在菜单管理中自行调整。

Loki 接入地址指向查询服务（例如 `http://loki:3100`），支持 Basic/Bearer 认证；多租户在高级配置中添加 `X-Scope-OrgID`。日志查询需要 `observability:logs` 权限，支持 LogQL 日志流、时间范围（最多 31 天）、最多 5000 条结果及日志详情。不会采集或复制日志；现已补充 Elasticsearch 和 ClickHouse 日志适配器，配置方式见 [日志查询接入](../../docs/log-query.md)；现已通过统一即时查询接入 Jaeger Trace ID 查询。


## 统一即时查询（2026-10-24 第二阶段）

新数据库直接提供一级「即时查询」工作台。已有数据库执行 `2026102402_explore.sql`，会迁移默认查询菜单并新增独立 SQL 查询权限（仅自动授权管理员），不删除旧菜单或修改数据源连接。无需先执行第一阶段菜单脚本；已执行第一阶段也可直接升级。更新后重新登录刷新菜单与权限。完整能力与限制参见 [查询接入说明](../../docs/log-query.md)。
